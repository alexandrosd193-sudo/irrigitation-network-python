# Αρδευτικό δίκτυο με Python

Σχεδιασμός αρδευτικού δικτύου με τεχνητή βροχή και εκ περιτροπής ζήτηση,
υλοποιημένος σε Python (Google Colab).

## Πρόοδος
- [x] Ζ1: Πρόγραμμα εκ περιτροπής ζήτησης, χρόνοι ποτίσματος
- [x] Ζ2: Διαστασιολόγηση αγωγών (PVC 10 atm)
- [ ] Ζ3: Απώλειες φορτίου, κρίσιμη διαδρομή
- [ ] Ζ4: Κόστος κατασκευής και λειτουργίας
- [ ] Ζ5: Ελεύθερη ζήτηση
- [ ] Ζ7: Αποστράγγιση

## Μέθοδος
Darcy-Weisbach με συντελεστή τριβής Swamee-Jain.
Επιλογή εμπορικής διαμέτρου: η πρώτη με εσωτερική διάμετρο ≥ D, ώστε U ≤ 1.5 m/s.

## Εργαλεία
Python, Google Colab, pandas
